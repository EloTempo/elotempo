# ==============================================================================
# 1. REGRA CENTRAL E AVISO METODOLÓGICO — NÃO FUNDIR AS DUAS LISTAS
# ==============================================================================
# Existem DUAS genealogias de Jesus no Novo Testamento, e elas DIVERGEM quase
# inteiramente entre o Rei Davi e José:
#
#   1. MATEUS 1:1-17:
#      - Ordem: descendente ("A gerou B").
#      - Início: Abraão.
#      - Linhagem régia: desce de Davi pelo rei SALOMÃO e pelos reis de Judá.
#      - Pai de José: JACÓ.
#      - Propósito: apresentar Jesus como Herdeiro Messiânico e Rei dos Judeus.
#
#   2. LUCAS 3:23-38:
#      - Ordem: ascendente ("Jesus, filho [como se cuidava] de José, de Heli...").
#      - Extensão: retrocede até Davi, Abraão, Adão e Deus.
#      - Linhagem não régia: desce de Davi por NATÃ (filho privado, não dinástico).
#      - Pai de José: HELI.
#      - Propósito: apresentar Jesus como Salvador Universal de toda a humanidade.
#
# ENTRE DAVI E JESUS, OS ÚNICOS NOMES COMUNS SÃO SALATIEL E ZOROBABEL.
# Nenhuma outra coincidência existe. Fundir as duas listas em uma só inventaria
# uma linhagem artificial que nenhum texto antigo atesta.
#
# Cada pessoa neste arquivo possui o metadado:
#   `linhagem: mateus | lucas | ambas`
# permitindo que a interface do aplicativo exiba uma árvore OU outra, ou as duas
# dispostas em paralelo.
#
# ==============================================================================
# 2. GRAUS DE CERTEZA POR VÍNCULO (ARESTA)
# ==============================================================================
# [EXPLÍCITO]  — Afirmado diretamente pelo texto bíblico (ex.: Salomão filho de Davi).
# [INFERIDO]   — Depende de harmonização ou identificação de personagens entre si (debatido).
# [TRADIÇÃO]   — Proveniente da hagiografia posterior (apócrifos/Legenda Áurea), sem base no cânon.
# [DIVERGENTE] — Fontes bíblicas se contradizem frontalmente; ambas registradas lado a lado.
#
# ==============================================================================
# 3. AS QUATRO HIPÓTESES HISTÓRICAS DE HARMONIZAÇÃO (Hipóteses, jamais fatos)
# ==============================================================================
# 1. Hipótese "Linha Legal de José x Linha Biológica de Maria":
#    Formulada expressamente por Annio de Viterbo (c. 1490) e popularizada após a
#    Reforma Protestante. Sustenta que Mateus dá a linha sucessória de José e Lucas
#    a linhagem biológica de Maria (sendo Heli o pai de Maria e sogro de José).
#    RESSALVA CRÍTICA: Lucas NÃO afirma isso. O texto grego diz "José, filho de Heli".
#    A atribuição a Maria é inferência piedosa tradicional, não fato documental.
#
# 2. Hipótese do Levirato (Júlio Africano, c. 200 d.C., em Eusébio, Hist. Ecl. 1.7):
#    Matã (linha de Salomão) e Melqui (linha de Natã) teriam casado sucessivamente
#    com a mesma mulher (chamada Está pela tradição). Jacó e Heli eram, assim,
#    meios-irmãos uterinos. Heli morreu sem filhos; Jacó desposou a viúva pelo
#    dever de levirato (Dt 25:5-10) e gerou José. Assim, José era filho natural
#    de Jacó (Mateus), mas legalmente filho de Heli (Lucas).
#
# 3. Hipótese da Linha Real x Linha Natural / Adoção (Santo Agostinho, c. 400 d.C.):
#    Em "De Consensu Evangelistarum", Agostinho propôs que um dos evangelistas
#    registrou o pai biológico e o outro um pai adotivo, distinguindo a realeza
#    legal da geração natural.
#
# 4. Leitura Acadêmica e Histórico-Crítica Moderna (Raymond Brown, Fitzmyer, PCB 1993):
#    Ambas as listas são construções teológicas autônomas do século I. Não eram
#    pesquisas de cartório, mas peças catequéticas para atestar a descendência
#    davídica requerida para o Messias no judaísmo do Segundo Templo.
#
# ==============================================================================
# 4. MOLDURA HERMENÊUTICA DA IGREJA CATÓLICA
# ==============================================================================
# - A Igreja NÃO define lista genealógica oficial e nunca canonizou uma harmonização.
# - Dogma / Doutrina firme: o VÍNCULO de que Jesus é verdadeiramente descendente
#   de Davi segundo a carne e filho de Abraão (Mt 1:1; Rm 1:3).
# - Diretriz Metodológica (Dei Verbum 12; Pontifícia Comissão Bíblica, 1993):
#   O texto sagrado deve ser lido considerando os gêneros literários de sua época.
# - Mateus estrutura sua genealogia em 3 séries de 14 gerações (Mt 1:17).
#   Para obter a simetria de 14 (duas vezes sete, perfeição), Mateus OMITIU reis
#   históricos documentados no Antigo Testamento (Acazias, Joás, Amazias e Joaquim).
#   14 é também o valor gemátrico do nome DAVI em hebraico (D-W-D = 4 + 6 + 4 = 14).
# - A inclusão de 4 mulheres por Mateus (Tamar, Raabe, Rute e a mulher de Urias)
#   é deliberada: estrangeiras e uniões irregulares que antecipam a graça universal.
#
# ==============================================================================
# 5. DESAMBIGUAÇÃO DE HOMÔNIMOS CRÍTICOS
# ==============================================================================
# - DOIS Jacós:
#     1. Jacó ben Isaac (Israel), patriarca do Antigo Testamento.
#     2. Jacó ben Matã, pai de José em Mateus 1:16.
# - TRÊS Tiagos no Novo Testamento:
#     1. Tiago Maior (filho de Zebedeu e Salomé; irmão do apóstolo João).
#     2. Tiago Menor (filho de Alfeu e Maria de Clopas; apóstolo).
#     3. Tiago, o Justo ("irmão do Senhor"; líder da Igreja de Jerusalém; Gl 1:19).
# - DOIS Judas:
#     1. Judas Tadeu (filho/irmão de Tiago; apóstolo).
#     2. Judas Iscariotes (o traidor).
# - QUATRO Josés principais:
#     1. José, esposo de Maria e pai legal de Jesus.
#     2. José, citado como "irmão do Senhor" (Mt 13:55).
#     3. José de Arimateia (membro do Sinédrio).
#     4. José/José ben Alfeu (irmão de Tiago Menor, Mt 27:56).
# - DOIS Simões:
#     1. Simão Pedro (Cefas, filho de Jonas).
#     2. Simão, o Zelote/Cananeu (apóstolo) / Simão "irmão do Senhor".
# - QUATRO Marias nos Evangelhos:
#     1. Maria, mãe de Jesus de Nazaré.
#     2. Maria de Clopas (presente na crucificação; Jo 19:25).
#     3. Maria Madalena (de Magdala).
#     4. Maria de Betânia (irmã de Marta e Lázaro).
#
# ==============================================================================

# --- RAMIFICAÇÃO D: PRIMOS DE JESUS [INFERIDO: As Duas Hipóteses de João 19:25] ---
# Em João 19:25, junto à cruz estavam:
# "a mãe de Jesus, e a irmã de sua mãe, Maria, mulher de Clopas, e Maria Madalena."
# Há duas formas gramaticais e exegéticas de ler essa lista:
#
#   HIPÓTESE A (Lista de 4 mulheres):
#   1. Maria, mãe de Jesus
#   2. A irmã de sua mãe (= Salomé, mãe dos filhos de Zebedeu em Mc 15:40)
#   3. Maria, mulher de Clopas
#   4. Maria Madalena
#   => Consequência: Salomé é tia materna de Jesus, logo Tiago Maior e João Evangelista são PRIMOS DE JESUS.
#
#   HIPÓTESE B (Lista de 3 mulheres ou aposição):
#   "a irmã de sua mãe, [isto é,] Maria de Clopas"
#   => Consequência: Maria de Clopas é irmã/cunhada de Maria. Como Clopas é identificado
#      com Alfeu por Hegesipo (irmão de José), os filhos de Alfeu (Tiago Menor e José)
#      são PRIMOS DE JESUS.

nome_registro: Hilfai / Kleopas

nacionalidades: Galileia (Império Romano)

linhagem: ambas
relacoes: casado com Maria de Clopas; pai do apóstolo Tiago Menor e de José; irmão de São José segundo Hegesipo [TRADIÇÃO/INFERIDO]   # -> Parentesco [INFERIDO: Hipótese B]

# A hagiografia medieval europeia (popularizada pela "Legenda Áurea" de Jacopo de
# Varazze, século XIII) desenvolveu a doutrina do Trinubium Annae (Três Casamentos de Ana):
#
#   1. Ana + Joaquim  --> Maria (Mãe de Jesus) --> JESUS
#   2. Ana + Cleofas  --> Maria Cleofas        --> Tiago Menor, José, Simão, Judas
#   3. Ana + Salomé   --> Maria Salomé         --> Tiago Maior e João Evangelista
#
# Sob esse esquema medieval, todos os apóstolos citados seriam primos em primeiro
# grau de Jesus por três meias-irmãs uterinas.
#

# Essa lenda NÃO possui qualquer fundamento no texto bíblico do Novo Testamento.
